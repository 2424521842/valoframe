# 瓦刻（VALOFRAME）v0.2.3

v0.2.3 是一次修复发布，解决 v0.2.2 中多账号素材库无法加载对局元数据的回归问题。v0.2.2 用户可通过应用内更新直接升级（更新包必须通过 Tauri/Minisign 签名验证）。

## 修复

### 多账号素材库的昵称、地图、英雄、KDA、胜负全部缺失

v0.2.2 把元数据锚点从单个重构为多个时，额外要求"仅有一个锚点"才允许回退到 ACLOS 应用数据目录。由于每个 `wonderfulVideos<账号>` 目录各自贡献一个锚点，**拥有两个及以上账号、或把素材分散存放在多个位置的用户，元数据回退会被整体关闭**。

默认安装布局下录像位于 `AppData\ACLOS`，而 `WonderfulDb`、`logs`、`Local Storage` 位于 `AppData\Roaming\ACLOS`，本就依赖这一回退，因此受影响的库会完全读不到对局信息：账号昵称、地图、英雄、KDA、比分与胜负全部为空。

本版本改为按锚点各自判断是否回退（`metadata_source_paths` 原本就只在锚点自身缺少元数据时才回退），恢复多账号与多位置布局的元数据加载，并新增覆盖该布局的回归测试。

- 素材、索引与用户整理数据（收藏、标签、备注、回收站）在此期间均未被破坏，元数据只是未写入。
- **升级后请在「扫描」页重新同步一次视频来源**，即可回填历史素材的对局元数据。

## 安装与升级

- 支持 Windows 10/11 x64，安装器为当前用户安装，不需要机器级管理员权限。
- 已安装 v0.2.1 或 v0.2.2 的用户可在「设置与关于」中检查更新并升级；更新包必须通过 Tauri/Minisign 签名验证，且不允许安装 prerelease 或降级版本。
- 数据库 schema 仍为 v18，本次升级不改变数据库结构。
- 目标电脑缺少 Microsoft Edge WebView2 Runtime 时，安装过程需要联网下载运行时。

## 数据与隐私

- 瓦刻保持本地优先，不提供云同步或遥测。素材、索引和用户整理数据留在本机。
- 问题反馈只在用户主动提交时生成诊断包；默认保存到本地，不会自动上传任何内容。
- 扫描、导入、重连和"仅移除索引"不会修改来源视频；只有回收站中经过二次确认且仍满足身份校验的素材可以进入永久删除流程。

## 已知限制

- 当前仅支持 MP4，不支持 MKV、实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 某些 HEVC/AV1 文件可能无法在 WebView2 中直接播放。HEVC 仍可由随包 FFmpeg 生成缩略图；AV1 只保留索引并提供系统播放器入口，不生成缩略图，且实际播放取决于系统解码能力。
