# 瓦刻（VALOFRAME）v0.2.5

v0.2.5 提升了全局文字可读性，修正扫描进度提前显示 100% 和 NVIDIA 待录入窗口操作按钮不可见的问题，并收紧广告配置的信任边界。v0.2.1 及以上用户可通过应用内更新直接升级（更新包必须通过 Tauri/Minisign 签名验证）。

## 下载

### GitHub（推荐）

[**下载 `VALOFRAME-0.2.5-x64-setup.exe`**](https://github.com/2424521842/valoframe/releases/download/v0.2.5/VALOFRAME-0.2.5-x64-setup.exe)

文件大小与 SHA-256 见同一 Release 的 `SHA256SUMS.txt`。应用内自动更新只从 GitHub 获取并强制验签。

## 改进与修复

### 字体更清晰，并可按需放大

- 全局默认基础字号从 14px 提升到 16px，主要工作区、卡片、筛选器、对话框和状态文案统一使用可缩放的排版变量。
- 「设置与关于」新增「标准」「大号」「特大」三级字体大小，切换后立即应用并保存到本机偏好；恢复默认设置会回到「标准」。
- 字体放大后，窄窗口中的导航、工具栏和表单允许合理换行或滚动，避免关键操作被裁切。

### 扫描进度不再提前显示完成

- 文件扫描只占进度条的 10%–85%；扫描文件结束后会依次显示「正在导入数据」「正在解析对局元数据」和「正在完成扫描收尾」。
- 只有任务真正进入完成终态才显示 100%；取消中、失败、部分完成和未知阶段均保留真实状态，不再让仍在工作的任务看起来已经结束。
- 进度条补充阶段化的无障碍标签和值说明，目录和后台阶段信息会同时保留。

### NVIDIA 待录入窗口在小屏幕中可正常提交

- 视频预览与分类表单改为受视口约束的内部滚动区，底部「取消」「录入到素材库」操作始终保持可到达。
- 账户、英雄或地图校验失败时会聚焦并滚动到第一个错误字段，键盘与屏幕阅读器可获得对应错误说明。
- 最小支持窗口和较大字体下均可继续预览、填写并提交，不再因内容高度超出窗口而看不到按钮。

### 缩略图与卡片反馈更及时

- 当前页缩略图改为优先加载，后台生成完成后能更快替换占位图。
- 已存在的卡片在缩略图等局部状态更新时不再重新播放入场动画，减少闪烁和跳动。

### 广告配置不再暴露给普通用户

- 设置页移除广告开关、素材接口和落地域名输入；升级时会忽略并清理 v0.2.4 遗留的三个广告偏好，同时保留其他设置。
- 素材接口与落地域名只能由维护者在构建时注入，WebView 和本机偏好都不能改变这两个信任边界。
- 配置缺失、接口失败、素材非法、投放时间无效或落地域名不受信任时一律安全降级为空广告位；失败刷新也不会继续展示过期活动。
- **本次 v0.2.5 稳定版未注入广告配置，广告通道保持停用。**

## 安装与升级

- 支持 Windows 10/11 x64，安装器为当前用户安装，不需要机器级管理员权限。
- 已安装 v0.2.1 及以上的用户可在「设置与关于」中检查更新并升级；更新包必须通过 Tauri/Minisign 签名验证，且不允许安装 prerelease 或降级版本。
- 数据库继续使用 schema v21，本版本不新增数据库迁移；字体大小保存在本机界面偏好中，旧广告偏好会在读取和保存时被移除。
- 目标电脑缺少 Microsoft Edge WebView2 Runtime 时，安装过程需要联网下载运行时。

## 数据与隐私

- 瓦刻保持本地优先，不提供云同步或遥测。素材、索引和用户整理数据留在本机。
- 本版不新增账号、游戏、文件路径或设备标识上传。广告通道在本次稳定构建中未配置，因此不会请求广告素材或记录展示与点击。
- 问题反馈只在用户主动提交时生成诊断包；默认保存到本地，不会自动上传任何内容。
- 扫描、导入、预览、重连和「仅移除索引」不会修改来源视频；只有回收站中经过二次确认且仍满足身份校验的素材可以进入永久删除流程。

## 已知限制

- 当前仅支持 MP4，不支持 MKV、实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 某些 HEVC/AV1 文件可能无法在 WebView2 中直接播放。HEVC 仍可由随包 FFmpeg 生成缩略图；AV1 只保留索引并提供系统播放器入口，不生成缩略图，且实际播放取决于系统解码能力。
