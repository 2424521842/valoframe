# 瓦刻（VALOFRAME）v0.2.2

v0.2.2 在 v0.2.1 的基础上加入 NVIDIA 待确认录像手动入库与问题反馈诊断包，并继续以免费个人社区版发布。这是个人社区稳定渠道的第二次发布，v0.2.1 用户可通过应用内更新直接升级（更新包必须通过 Tauri/Minisign 签名验证）。

## 主要更新

### NVIDIA 待确认录像手动入库

- NVIDIA App/ShadowPlay 等录制源下的录像不再自动进入素材库，扫描时登记到"待确认"队列，并显示待确认数量。
- 用户可为每段待确认录像填写账号、地图、英雄等分类信息后一次性导入素材库；导入在一个事务内创建素材、对局与元数据行。
- 支持忽略与取消忽略待确认项；扫描、重连与缩略图流程对新队列保持只读边界。

### 问题反馈诊断包

- 预览页新增"反馈问题"入口：生成脱敏诊断包（应用版本、素材元数据摘要、可选 0–3 张采样帧与完整视频，最大 1 GiB）。
- 当前唯一默认方式为保存本地 zip 文件，再通过 QQ 群、邮件或网盘发送；直传接口能力已保留，待后台就绪后在「设置 → 反馈」重新开放配置。
- 上传失败自动回退为保存文件；诊断包内容与直传契约见 `docs/FEEDBACK_UPLOAD_SPEC.md`。

### 其他

- 数据库 schema 升级到 v18（新增 pending_manual_clips 表与扫描汇总待确认计数），迁移前自动创建 SQLite Online Backup。
- 扫描汇总、路径重连、缩略图与元数据摄入的若干修正；文档与测试同步更新。

## 安装与升级

- 支持 Windows 10/11 x64，安装器为当前用户安装，不需要机器级管理员权限。
- 已安装 v0.2.1 的用户可在「设置与关于」中检查更新并升级；更新包必须通过 Tauri/Minisign 签名验证，且不允许安装 prerelease 或降级版本。
- 目标电脑缺少 Microsoft Edge WebView2 Runtime 时，安装过程需要联网下载运行时。

## 数据与隐私

- 瓦刻保持本地优先，不提供云同步或遥测。素材、索引和用户整理数据留在本机。
- 问题反馈只在用户主动提交时生成诊断包；默认保存到本地，不会自动上传任何内容。
- 扫描、导入、重连和"仅移除索引"不会修改来源视频；只有回收站中经过二次确认且仍满足身份校验的素材可以进入永久删除流程。

## 已知限制

- 当前仅支持 MP4，不支持 MKV、实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 某些 HEVC/AV1 文件可能无法在 WebView2 中直接播放。HEVC 仍可由随包 FFmpeg 生成缩略图；AV1 只保留索引并提供系统播放器入口，不生成缩略图，且实际播放取决于系统解码能力。
