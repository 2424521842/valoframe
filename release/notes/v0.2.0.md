# 瓦刻（VALOFRAME）v0.2.0

> 历史说明：本版本不作为当前 updater 发布起点。用户应手动安装 `v0.2.1`，再通过应用内更新升级到 `v0.2.2`。

v0.2.0 是国际服素材接入与高效筛选的历史计划版本；实际受签名保护的应用内更新起点调整为 v0.2.1。

## 新功能

### 更多本地录像来源

- 扫描页现在可以注册无畏时刻、NVIDIA App/ShadowPlay、Valorant Tracker 和普通录像目录。
- NVIDIA、Tracker 和普通目录使用只读递归 MP4 扫描，保留来源、相对目录和本地录制日期分组。
- 已启用来源可以在启动后后台增量同步，也可以手动立即同步。
- H.264、HEVC 和 AV1 视频都可以建立索引；随包 FFmpeg 为 H.264 与 HEVC 生成缩略图。AV1 仍会保留素材并提供外部播放器入口，但本版不生成 AV1 缩略图。
- 扫描不会跟随符号链接、junction 或其他 reparse point，也不会越出用户授权的根目录。

### 播放器快捷键

- `Space` / `K`：播放或暂停。
- `←` / `→`：后退或前进 5 秒。
- `Shift + ←/→`、`J/L`：后退或前进 10 秒。
- `M`：静音或恢复声音。
- 输入、备注、下拉菜单和对话框聚焦时不会误触播放器操作。

### 卡片式快速筛选

- 可按来源、日期和标签创建一次固定候选范围的筛选会话。
- 左滑或 `A` 标记“不喜欢”；右滑或 `D` 标记“喜欢”并同步收藏。
- 支持按钮、键盘、鼠标/触摸手势、静音预览、有限预取和 `Ctrl+Z` 撤销。
- “不喜欢”只是一项整理决定，不会进入回收站，也不会删除或修改原视频。
- 素材库可以按未筛选、喜欢和不喜欢查看，并可重置筛选决定。

### 应用内更新

- “设置与关于”显示当前版本、更新状态、发布说明和下载进度。
- 应用每天最多自动检查一次；手动检查不受此限制。
- 发现新稳定版本后，只有在用户确认后才下载；下载完成后会再次确认安装。
- 下载可以取消。扫描、永久删除或其他关键写入进行中时，安装会被阻止，任务结束后可重试。

## 首次升级说明

v0.1.0-beta.1 不包含更新模块，无法自行发现或安装后续版本。当前用户需要从 GitHub Release 手动安装 v0.2.1 一次；此后才可从“设置与关于”升级到正确签名且版本更高的 v0.2.2 及后续稳定版。

安装 v0.2.0 会把现有 SQLite 数据库原子升级到 schema v14，并在迁移前创建备份。收藏会对应为“喜欢”；已有标签、备注、回收状态、回收身份快照、永久删除意图和素材引用保持不变。安装或升级不会移动、重命名或删除来源视频。

## 系统与媒体要求

- Windows 10/11 x64，最小窗口为 760×560。
- 安装器在缺少 WebView2 时需要联网下载 Microsoft WebView2 Runtime；离线机器应先安装 WebView2。
- 内嵌播放能力仍取决于 Windows/WebView2 的媒体解码支持。v0.2.0 不生成转码代理，也不支持 MKV。
- Tracker 仅作为用户选择的本地视频目录，不读取其私有数据库，也不调用 Tracker API。

## 更新与下载安全

- 稳定更新只使用项目固定的 GitHub HTTPS endpoint。
- updater 包必须通过 Tauri Minisign 校验；Windows 主程序和安装器同时使用独立的 Authenticode 签名及可信时间戳。
- Release 附带 `SHA256SUMS.txt`；安装器、updater 包、`.sig`、`latest.json` 和发布说明在公开前会逐项复核。
- 不提供跳过签名、安装 prerelease 或降级的入口。

如果检查、下载或签名验证失败，当前版本不会被替换，本地素材功能仍可离线使用。请保持应用开启并稍后重试；若安装失败，重新启动当前版本后可再次检查。发布回退只会通过撤下有问题的更新入口并发布版本号更高的修复版完成，不会要求通过 updater 降级。

## 数据与隐私

- 新增来源扫描、快速筛选和更新检查不会修改来源视频。
- 收藏和筛选决定只保存在瓦刻数据库中；收藏不等于复制备份，第三方录制工具仍可能按自己的策略清理文件。
- v0.2.0 不收集遥测。新增联网行为仅用于用户授权的 GitHub 版本检查、更新下载以及缺少 WebView2 时的 Microsoft Runtime 引导。

## 已知限制

- 不提供实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 正在写入或扫描期间发生变化的视频会延后到下次同步。
- 某些 HEVC/AV1 文件可能只能交给系统默认外部播放器，实际播放取决于系统解码能力；AV1 可保留索引，但本版不生成 AV1 缩略图。
