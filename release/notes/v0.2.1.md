# 瓦刻（VALOFRAME）v0.2.1

v0.2.1 是自 v0.1.0-beta.1 以来的一次重要桌面版升级，也是后续稳定应用内更新的手动安装起点。本轮重点完善了多来源接入、快速挑片、扫描可靠性、目录恢复和本地数据安全。

## 主要更新

### 更多本地录像来源

- 支持注册无畏时刻、NVIDIA App/ShadowPlay、Valorant Tracker 和普通 MP4 目录。
- NVIDIA、Tracker 与普通目录只在用户授权根目录内递归扫描 MP4；不读取 Tracker 私有数据库或 API，不跟随符号链接、junction 或其他 reparse point。
- H.264、HEVC 与 AV1 视频均可建立索引和生成缩略图；WebView2 无法内嵌播放时会保留素材，并提供系统播放器入口。

### 独立的快速挑片工作流

- 快速挑片拥有独立范围，不再继承或修改素材库当前筛选；可按账号、英雄、地图、模式、日期、视频类型、标签和搜索词收窄候选素材。
- 支持入选、待定、跳过、撤销、保存进度后继续，以及提前结束并查看结果。
- 详情预览与快速挑片均支持全屏播放：可使用全屏按钮、`F` 或双击视频进入，使用 `Esc` 退出。
- 预览继续支持 `Space` / `K` 播放暂停、方向键与 `J` / `L` 快进快退、`M` 静音；输入框、下拉菜单和对话框聚焦时不会误触快捷键。

### 更可靠的扫描反馈

- 扫描页会显示每个启用来源是“今天扫描”“N 天未扫描”还是“尚未完成首次扫描”。从未完整扫描或达到 7 个本地自然日未扫描时会显示提醒。
- 只有完整成功的扫描才更新来源新鲜度；`partial`、`cancelled` 和 `failed` 不会伪装成成功扫描。
- 每个扫描任务终态会按任务 ID 去重并准确显示新增数量，包括“新增 0 个视频”；无法恢复摘要时会明确显示数量不可用。
- 新增“启动时自动扫描”设置，默认关闭。开启后只同步已加入自动同步的来源，短时间内重新启动不会重复扫描，手动同步始终可用。

### 来源恢复与安全重连

- 同一已注册来源内的文件或子目录改名，会优先按规范化路径、唯一 Windows 稳定文件身份，再按无歧义的旧库指纹安全重连。
- 可信重连会保留 clip ID、收藏、标签、备注、评审决定和结构化元数据；复制、硬链接或歧义候选不会被猜测合并。
- 来源根移动后可先预览再明确提交新位置；提交会重新验证授权边界、来源重叠、回收素材、删除 intent 和关键任务互斥。
- missing 或来源不可用的普通素材支持单条和批量“仅移除索引”，不会删除、移动或修改磁盘视频。

### 视频类型与事件时间轴修正

- 三杀、四杀、五杀、六杀、击杀集锦和死亡时刻会解析为唯一规范类别，并显示在素材卡片上。
- 修复击杀集锦因事件数量而被误判为普通多杀，以及英文单词或中文子串造成的类型误判。
- 普通多杀继续使用“分段起点 + 事件相对时间”；击杀/死亡集锦使用视频绝对时间，不再重复叠加分段起点。
- 击杀类高光只显示本人击杀并使用红色准星；死亡集锦只显示本人死亡并使用紫色骷髅。超出视频时长的事件不会被裁剪或渲染。

### 大素材库与数据升级

- 大素材库采用后端分页和分层虚拟化；批量整理操作使用单事务，并同步当前页、详情与筛选统计。
- 修复移入回收站或执行等价查询刷新后，素材库滚动位置跳回顶部的问题。
- 数据库目标版本升级为 schema v16。v13、v14 和 v15 数据库会在迁移前创建 SQLite Online Backup，并在单事务中升级。
- 迁移保留来源、clip ID、收藏、标签、备注、评审、缩略图、回收快照、永久删除 intent 和原始元数据。

## 安装与升级

- 支持 Windows 10/11 x64，安装器为当前用户安装，不需要机器级管理员安装范围。
- v0.1.0-beta.1 不包含稳定更新配置，无法应用内升级到本版本；旧用户需要手动安装 v0.2.1 一次。
- 安装 v0.2.1 后，后续版本可通过设置中的稳定通道升级；更新包必须通过 Tauri/Minisign 签名验证，且不允许安装 prerelease 或降级版本。
- 目标电脑缺少 Microsoft Edge WebView2 Runtime 时，安装过程需要联网下载运行时。
- Windows Authenticode 与 Tauri 更新签名是两套不同机制。当前安装器可能显示“未知发布者”或 SmartScreen 提示，请只从项目 Release 下载并核对 `SHA256SUMS.txt`。

## 数据与隐私

- 瓦刻保持本地优先，不提供云同步或遥测。素材、索引和用户整理数据留在本机。
- 扫描、重连、根目录恢复和“仅移除索引”不会修改来源视频；只有回收站中经过二次确认且仍满足身份校验的素材可以进入永久删除流程。
- 扫描、永久删除、视频导出、来源根重定位与更新安装由同一后端关键任务门禁互斥，失败或取消不会替换当前安装或放宽文件权限。

## 已知限制

- 当前仅支持 MP4，不支持 MKV、实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 某些 HEVC/AV1 文件可能无法在 WebView2 中直接播放，但仍可保留索引、生成缩略图并使用系统默认播放器打开。
- Windows 稳定文件身份是最佳努力能力；跨来源或跨卷移动不会自动判断为同一素材，来源根移动需要用户明确选择并确认。
- 对仍可访问且不符合“仅移除索引”资格的素材，原有回收站与永久删除边界保持不变。
