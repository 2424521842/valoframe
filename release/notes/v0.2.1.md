# 瓦刻（VALOFRAME）v0.2.1

v0.2.1 是扫描可靠性、失联来源恢复与 ACLOS 时间轴修订版本，也是旧用户需要手动安装一次的稳定 updater 起始版本。它延续本地优先和只读索引原则，不扩大永久删除权限。

## 扫描反馈

- 扫描页始终显示每个启用来源是“今天扫描”“N 天未扫描”还是“尚未完成首次扫描”。任一启用来源达到 7 个本地自然日未完成完整扫描，或从未完整扫描时，全局活动提醒会突出来源数量和最长未扫描天数；停用来源不参与统计。
- 只有完整成功的扫描才更新来源新鲜度。`partial`、`cancelled` 和 `failed` 不会伪装为成功扫描；UTC 时间会按用户本地自然日换算，并安全处理跨午夜、夏令时、非法值和未来时间。
- 每个扫描任务终态都按 job ID 去重显示新增数量，包括“新增 0 个视频”。部分完成或取消会显示已安全写入的数量和实际终态；无法恢复任务摘要时明确显示“新增数量不可用”，不会猜测为 0。
- 提醒继续集中在扫描页与现有全局活动通知中，不新增启动弹窗。

## 来源与目录恢复

- 同一已注册来源内的文件或子目录改名，会优先按规范化路径、唯一 Windows 稳定文件身份，再按旧库中唯一的“文件名 + 大小 + 修改时间”安全重连。可信重连保留 clip ID、收藏、标签、备注、评审决定和结构化元数据。
- 复制文件、硬链接、重复身份或重复旧指纹不会被猜测合并；旧记录按完整扫描结果收敛为 missing，新路径作为新素材写入并报告有限告警。身份读取失败不会阻断正常索引。
- 来源根移动后，可先预览再由用户明确提交新根。提交会重新验证普通目录、reparse point、授权根边界、来源重叠、可信匹配、回收素材、删除 intent 及关键任务互斥，并在单事务中更新来源与根内引用。
- 根重新定位本身不刷新 `lastScanAt`；提交后立即启动既有来源同步，只有成功完整同步才更新扫描新鲜度。
- missing 或来源不可用的普通素材支持单条和批量“仅移除索引”。确认后会清除瓦刻内该素材的标签、备注等索引状态，但绝不会删除、移动或修改磁盘视频，也不会创建离线回收状态。

## 击杀与死亡时间轴

- ACLOS 的 `KilledIsMe` 会写入结构化事件。击杀类高光只显示本人击杀，使用红色准星；死亡集锦只显示本人死亡，使用紫色骷髅。助攻、市场、空类型及其他事件不显示标记。
- 普通三杀、四杀等高光继续使用“分段起点 + 事件相对时间”；击杀/死亡集锦中的事件时间按视频绝对时间解释，不再重复叠加分段起点。
- 超出视频 `[0, duration]` 的事件不会裁剪或渲染，并会留下元数据警告。图例、tooltip、无障碍名称和点击跳转统一使用“本人击杀”“本人死亡”及修正后的秒数。

## 数据库升级

- 数据库目标版本为 schema v16。v15 的稳定文件身份、`killed_is_me` 与扫描摘要字段保持不变；v16 统一普通/Win32 verbatim 路径键，并安全合并可确定的重复索引。
- v0.2.0 的 schema v14 数据库升级前会生成标记为 `pre-v14-to-v16` 的 SQLite Online Backup；仍处于 v13 的数据库会一次性备份为 `pre-v13-to-v16`，并在同一个事务中安全迁移到 v16。
- 迁移保留来源、clip ID、收藏、标签、备注、评审、缩略图、回收快照、永久删除 intent 和原始 JSON。无法可靠修复的旧集锦事件时间不会猜测，等待下次 ACLOS 重扫重建。
- `user_version > 16` 的未来数据库继续拒绝打开且不修改文件；文件身份不可用时身份字段保持空，路径索引仍可正常工作。

## 安全边界

- 自动重连只在同一授权来源内工作；不跨来源猜测、不扫描未授权目录、不跟随符号链接或 junction，也不对视频做大文件内容哈希。
- 回收站仍是永久删除授权边界。根恢复和仅移除索引不会补造回收快照、放宽删除 intent、跳过句柄身份验证或直接调用磁盘删除路径。
- 来源存在回收素材或删除 intent，或扫描、永久删除、来源重定位、更新安装等关键任务冲突时，根重新定位会失败关闭。

## 安装与应用内更新

- `v0.1.0-beta.1` 不能直接应用内升级；用户需要从本 Release 手动安装 `v0.2.1`。完成后，应用可通过受信 Tauri 签名和固定稳定端点升级到 `v0.2.2` 及后续稳定版本。
- Community Beta、内部 RC、prerelease 或未配置公钥的构建不进入稳定更新通道。
- 扫描、永久删除、来源重定位或其他关键写入进行中时禁止安装更新；不会静默下载、跳过签名、安装 prerelease 或降级。
- Tauri updater 签名是稳定更新的强制要求。Windows Authenticode 当前可选，因此安装器可能显示“未知发布者”或 SmartScreen 提示；这不影响更新包自身的 Tauri 签名验证。

## 已知限制

- 稳定文件身份是 Windows 上的最佳努力能力；不可用时会继续索引，但不会据此进行不可信合并。
- 跨来源或跨卷移动不会自动猜测为同一素材；来源根移动必须由用户明确选择新位置并通过预览验证。
- 对仍可访问且不符合“仅移除索引”资格的素材，原有回收站和永久删除流程保持不变。
