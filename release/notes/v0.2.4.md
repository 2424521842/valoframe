# 瓦刻（VALOFRAME）v0.2.4

v0.2.4 修正了素材库的两类分组与时间显示问题，为待录入录像加上应用内预览，并首次引入默认关闭的可选广告位。v0.2.1 及以上用户可通过应用内更新直接升级（更新包必须通过 Tauri/Minisign 签名验证）。

## 下载

### GitHub（推荐）

[**下载 `VALOFRAME-0.2.4-x64-setup.exe`**](https://github.com/2424521842/valoframe/releases/download/v0.2.4/VALOFRAME-0.2.4-x64-setup.exe)

安装前请核对本页 `SHA256SUMS.txt` 中的 SHA-256；应用内自动更新只从 GitHub 获取并强制验签。

## 修复

### 原始录像被折叠成同一场对局

无畏时刻把每场对局的高光放在各自的 `<对局 ID>/` 目录下，但完整对局的原始录像统一落在共享的 `record/` 目录。此前扫描把整个 `record/` 当作一个分组，导致**多场互不相关的对局被折叠显示在同一个对局标题下**。

本版按文件为 `record/` 中的每段录像单独建组，封面也只绑定到文件名真正匹配的那段录像，不再跨录像复用。已有素材库在升级时由 schema v20 迁移就地拆分历史分组。

### 手动录入的录像显示原始时间戳

NVIDIA 手动录入此前把扫描得到的裸 Unix 秒直接写入对局时间字段，而其他元数据通道写入的是可读日期时间，素材库因此把类似 `1782634272` 的原始纪元秒当作比赛时间显示。

本版在录入时统一转换为可读日期时间格式，并由 schema v19 迁移就地重写历史数据；官方通道写入的日期时间保持不变。同时前端时间格式化对无法解析的取值返回「时间未知」，不再因单个坏值导致整个页面白屏。

## 新功能

### 待录入录像可在应用内预览

手动分类对话框现在直接内嵌播放器，可以先看内容再填写账号、地图、英雄，不必另外打开文件；同时显示文件体积。待录入录像还没有素材行，因此后端在投递任何字节前会重新校验该路径仍是授权来源目录内的普通 MP4 文件。WebView2 解码链不支持该文件时会给出提示，分类信息仍可正常填写。

### 挑片可直接提前结束

本轮已经处理过素材后，挑片页会显示「提前结束并查看结果」按钮，并标明已入选与剩余数量，不必再从退出对话框里找入口。挑片范围页在存在筛选条件时也新增了「清空全部条件」的快捷操作。

### 可选广告位（默认关闭）

设置页新增「显示广告」开关，**默认关闭且未配置任何接口，即开箱状态下不存在任何广告行为**。这是为项目长期维护预留的可选支持方式，开启与否完全由用户决定。

出于本应用具备全盘视频读取与原始文件删除能力的考虑，这个广告位不引入任何第三方 SDK：

- 应用 CSP 不放开，不加载外部脚本，不使用 iframe，只支持静态图文素材，不接受视频、开屏或插屏广告；
- 素材图由本机后端下载并缓存到本地，再经应用内部协议投递给界面，**界面本身全程不连接任何外部服务器**；
- 点击时由后端从库内模板重建 URL，校验域名命中用户配置的允许列表后调用系统默认浏览器打开；允许列表为空时阻止全部点击；
- 传出内容仅广告位标识与一次性点击标识，不含账号、游戏、文件或设备信息。

对接契约见 `docs/AD_INTEGRATION_SPEC.md`，数据边界见 `docs/PRIVACY.md`。

## 安装与升级

- 支持 Windows 10/11 x64，安装器为当前用户安装，不需要机器级管理员权限。
- 已安装 v0.2.1 及以上的用户可在「设置与关于」中检查更新并升级；更新包必须通过 Tauri/Minisign 签名验证，且不允许安装 prerelease 或降级版本。
- 数据库 schema 从 v18 升级到 v21：v19 修正手动录入的比赛时间，v20 拆分共享原始录像分组，v21 新增三张广告位表（仅在开启广告后写入）。升级前仍创建经校验的数据库备份，任一数据修复失败都会连同版本号更新一起回滚。
- **升级后建议在「扫描」页重新同步一次视频来源**，让原始录像分组与封面绑定按新规则重建。
- 目标电脑缺少 Microsoft Edge WebView2 Runtime 时，安装过程需要联网下载运行时。

## 数据与隐私

- 瓦刻保持本地优先，不提供云同步或遥测。素材、索引和用户整理数据留在本机。
- 广告位默认关闭；开启后只下载图文素材，不上传任何用户数据。关闭开关后不再发起任何广告请求。
- 问题反馈只在用户主动提交时生成诊断包；默认保存到本地，不会自动上传任何内容。
- 扫描、导入、预览、重连和「仅移除索引」不会修改来源视频；只有回收站中经过二次确认且仍满足身份校验的素材可以进入永久删除流程。

## 已知限制

- 当前仅支持 MP4，不支持 MKV、实时目录监听、云同步、自动转码、静默安装或 Beta 更新通道。
- 某些 HEVC/AV1 文件可能无法在 WebView2 中直接播放，待录入预览同样受此限制。HEVC 仍可由随包 FFmpeg 生成缩略图；AV1 只保留索引并提供系统播放器入口，不生成缩略图，且实际播放取决于系统解码能力。
