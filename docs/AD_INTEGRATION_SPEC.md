# 广告位对接接口规范

本文档描述瓦刻（VALOFRAME）内置广告位的对接契约，供广告方（联盟 / 代理 / 直客）实现其投放侧接口。

瓦刻是 Windows 桌面应用（Tauri 2 + WebView2），**不是浏览器网页**。这决定了对接方式与常规网页广告位有本质差异，请先阅读第 1 节。

---

## 1. 技术前提（不可协商部分）

瓦刻的应用内容安全策略（CSP）为 `script-src 'self'`、`frame-src 'none'`，且不允许任何外域资源直接加载。原因：本应用具备全盘视频文件读取权限与用户原始文件永久删除能力，在其中执行第三方远程代码的风险不可接受。

因此：

| 常规做法 | 瓦刻是否支持 | 说明 |
| --- | --- | --- |
| JavaScript SDK / 广告标签 | **不支持** | `script-src 'self'`，外部脚本无法加载 |
| iframe 广告位 | **不支持** | `frame-src 'none'` |
| 前端直连广告方 CDN 取图 | **不支持** | 前端无外域网络权限 |
| 视频广告 / 自动播放 | **不支持** | 产品决策，不接受 |
| 开屏 / 插屏广告 | **不支持** | 产品决策，不接受 |
| 静态图文素材 + 落地页跳转 | **支持** | 唯一支持的形式 |

实际工作方式：

1. 瓦刻维护者在发行构建中嵌入受信任的素材清单入口与落地域名，客户端后端（Rust）请求广告方的**素材清单接口**（第 2 节）；
2. 素材图由客户端后端下载并缓存到本机，再经应用内部协议投递给界面，前端全程零外域请求；
3. 用户点击广告卡时，客户端生成唯一 `click_id`，填入广告方提供的**落地页 URL 模板**（第 3 节），调用系统默认浏览器打开；
4. 表单填写、转化统计均在广告方落地页与后台完成，瓦刻不参与（第 6 节）。

---

## 2. 素材清单接口（广告方提供）

由瓦刻客户端主动拉取，广告方无需向客户端推送。接口地址由瓦刻维护者在发行构建中固定配置，普通用户不能输入或替换该地址。

```text
GET {广告方提供的清单接口地址}
Accept: application/json
```

要求：

- 必须为 `https://`（客户端本机联调允许 `http://localhost` / `http://127.0.0.1` / `http://[::1]`）；
- 地址长度不超过 300 字符；
- 无需鉴权；若需鉴权，只接受固定 query 参数或固定请求头形式的静态密钥，不接受需要动态签名或 Cookie 会话的方案。

### 2.1 响应格式

```json
{
  "schemaVersion": 1,
  "creatives": [
    {
      "creativeId": "cr-20260801-001",
      "title": "标题，不超过 24 字",
      "body": "描述文案，不超过 60 字",
      "imageUrl": "https://cdn.example.com/creatives/cr-20260801-001.jpg",
      "landingUrlTemplate": "https://ad.example.com/lp/1001?sub_id={sub_id}&click_id={click_id}",
      "advertiserName": "广告主名称（必填，用于界面署名）",
      "weight": 100,
      "startAt": "2026-08-01T00:00:00Z",
      "endAt": "2026-08-31T23:59:59Z"
    }
  ]
}
```

字段约定：

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| creativeId | 是 | 稳定唯一标识，用于对账与去重；素材内容变更须换新 ID |
| title | 是 | ≤ 24 字 |
| body | 否 | ≤ 60 字 |
| imageUrl | 是 | https；PNG 或 JPEG；建议 720×400（16:9 附近）；**单张 ≤ 512 KiB** |
| landingUrlTemplate | 是 | 见第 3 节 |
| advertiserName | 是 | ≤ 20 字，界面上会与「广告」标识一同展示 |
| weight | 否 | 正整数，多素材轮播权重，缺省 100 |
| startAt / endAt | 否 | RFC 3339；缺省表示长期有效 |

### 2.2 客户端行为

- 应用启动后由 Rust 后端从固定入口拉取；清单返回空素材列表即表示后台停用当前活动，无需用户改设置或重新安装；
- 素材图下载后会**校验文件魔数与体积**，非 PNG/JPEG 或超限的素材被静默丢弃；
- 清单接口不可达、超时、返回非 2xx、JSON 不合规或受信任配置不完整时，客户端 **fail closed**：静默隐藏广告位，不回退显示过期缓存，也不向用户弹出全局错误；
- `startAt` / `endAt` 必须是有效 RFC 3339 且起止顺序正确；非法投放期的素材会被丢弃；
- 普通设置中没有广告启停、接口地址或落地域名入口。发行维护者通过构建环境中的 `VALOFRAME_AD_MANIFEST_ENDPOINT` 与 `VALOFRAME_AD_ALLOWED_HOSTS` 固定客户端信任边界；未嵌入接口时广告链路保持停用。

## 3. 落地页 URL 模板与归因

`landingUrlTemplate` 必须支持以下占位符，客户端在点击时替换：

| 占位符 | 含义 | 示例值 |
| --- | --- | --- |
| `{sub_id}` | 广告位标识（区分侧栏位 / 库页位），由双方约定 | `valoframe-sidebar` |
| `{click_id}` | 客户端为**每一次点击**生成的唯一 ID | `vf-8123-1767000000123-a4f2` |

约束：

- 模板必须为 `https://`；
- 模板 host 必须在双方约定并由瓦刻维护者嵌入发行构建的**落地页域名白名单**内。客户端会在打开浏览器前校验最终 URL 的协议与 host，不匹配则拒绝打开——这是防止清单被篡改导致任意协议执行的必要措施。素材清单本身无权扩张该白名单；请提前提供完整的落地页域名列表，包含所有可能的跳转中转域名；
- 客户端不会对模板做除占位符替换以外的任何改写。

### 3.1 归因所需的广告方能力（重要）

以下三项是本次合作能否正常结算与对账的前提：

1. **sub_id 维度 + 日维度报表，且可导出。** 缺少此项，瓦刻无法核对自身贡献量，只能被动接受广告方报数，不具备合作基础。
2. **CPL 场景必须提供 S2S postback（转化回传）。** 广告方在收到有效表单后，回调瓦刻方约定的接口并带回原始 `click_id`。缺少此项，表单转化完全无法自主对账。
3. **明确转化归因窗口**，即点击后多长时间内的表单提交计入该次点击。

瓦刻客户端本地会记录每一次点击的 `click_id`、`creativeId`、广告位与时间戳，作为对账依据。

## 4. 结算口径

需在合同中明确，不接受留白：

- CPC / CPL 单价，是否分行业、分时段浮动；
- 以广告方后台数据结算，但须约定**双方数据差异容忍区间（建议 ≤ 5%）**，超出时广告方须提供明细供核对；
- **无效点击 / 无效线索的判定规则须逐条写明**：重复 IP 规则、同设备去重窗口、重复提交时限。不接受「平台判定为无效的不予结算」这类空白条款；
- 扣量上限、结算周期、最低结算门槛、账期；
- 合同主体、发票类型与税率。

---

## 5. 资质与内容责任

广告方须提供：

- 广告主营业执照；
- 所属行业的广告发布许可（医疗、药品、金融、教育、游戏等类目各有额外要求）；
- 广告内容合法性由广告方承担的书面责任条款，含被监管机关处罚时的责任划分与赔偿安排。

**禁投类目**（瓦刻方单方面保留最终审核与下架权）：

- 赌博、色情、烟草、违禁药品；
- 虚假医疗、无资质金融放贷；
- **游戏外挂、代练、私服、账号交易** —— 瓦刻是 VALORANT（无畏契约）周边工具，投放此类广告将直接招致游戏发行方追究，属绝对禁投；
- 任何仿冒瓦刻自身或伪装为应用功能提示的素材。

---

## 6. 数据合规

- 瓦刻定位为「全本地处理、不上传用户数据」的工具。广告方**不得**通过任何 SDK、像素、指纹脚本收集瓦刻用户数据——技术上也无法实现（见第 1 节）。
- 客户端向广告方传递的数据仅限于：`sub_id`、`click_id`，以及用户浏览器访问落地页时由浏览器自身携带的常规信息（IP、UA）。瓦刻不传递任何账号、游戏、文件或设备标识信息。
- **CPL 表单必须位于广告方落地页上。** 瓦刻应用内不收集姓名、手机号等任何个人信息，不接受「应用内嵌表单再回传」的方案。
- 若广告方的追踪方案需要任何形式的设备标识，须提前提供完整的收集字段清单，否则无法写入瓦刻的隐私政策，合作无法推进。

---

## 7. 界面呈现（瓦刻方实现，供广告方确认合规性）

- 广告卡位于应用侧栏底部与素材库页内，为静态图文卡片，不遮挡、不打断用户操作；
- 每个广告卡均带**显著的「广告」标识**及 `advertiserName` 署名，符合《互联网广告管理办法》对广告可识别性的要求；
- 广告活动的启停、素材、有效期和落地策略由瓦刻维护后台统一控制，普通用户设置不承载运营配置。

---

## 8. 联调清单

对接开始前，请广告方提供：

- [ ] 素材清单接口地址（https，交付瓦刻维护者写入受信任发行配置）
- [ ] 落地页域名白名单（完整，含中转域名；由瓦刻维护者写入受信任发行配置）
- [ ] `sub_id` 取值约定
- [ ] sub_id + 日维度报表后台账号
- [ ] S2S postback 接口文档（CPL 必需）
- [ ] 转化归因窗口时长
- [ ] CPC / CPL 单价与无效流量判定规则（书面）
- [ ] 广告主资质文件
- [ ] 首批素材（符合第 2.1 节尺寸与体积约束）
