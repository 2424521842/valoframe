# 本地数据与隐私说明（开发预览）

本文说明瓦刻在当前开发预览中读取、保存和传输的数据。它用于帮助测试者评估风险，不代替最终隐私政策或适用地区的法律审核。

## 一句话结论

瓦刻的应用功能在本机处理素材和索引，不提供账号系统、云同步、遥测或自动上传；但它会在本地 SQLite 中保存可识别玩家和文件来源的信息，部分 WonderfulDb 原始记录会以明文 JSON 持久化，应用数据库本身未额外加密。内置广告位由维护者后台统一控制；发行构建未配置活动或后台停用时不展示，启用后仅从固定受信任入口下载图文素材并在点击时跳转浏览器，不上传用户数据。

## 读取的数据

根据用户选择和本机可用来源，应用可能只读访问：

- ACLOS 高光视频、封面、目录结构、文件名、路径、大小和修改时间；
- WonderfulDb 中的账号、对局、统计与事件记录；
- `videoExportTmp/config-*.json`、`highlight.log` 与 Local Storage LevelDB；
- 用户在应用中创建的标签、收藏、备注、回收状态和导出目标。

应用不读取游戏进程或内存，不绕过操作系统文件权限。

## 本地保存的数据

应用数据目录中的 `highlight-index.sqlite3` 及其备份可能包含：

- 视频绝对路径、来源目录、文件指纹、大小、时间和媒体状态；
- 玩家名、账号显示名、OpenID、稳定账号标识、对局标识、英雄、地图、模式、比分与事件；
- 用户收藏、标签、备注、回收状态和永久删除意图；
- 提取文本和用于索引/排错的元数据；
- WonderfulDb 的部分完整 snapshot/event 记录序列化后的 `raw_json`。

这些 SQLite 文件未由瓦刻使用 SQLCipher 或等价机制额外加密。Windows 账户权限、磁盘加密和备份策略决定静态数据的主要保护强度。

应用还可能保存：

- 数据库迁移前备份，默认保留最近 3 份；
- 缩略图缓存和缩略图队列状态；
- 开发模式下终端输出或测试人员主动保存的日志。

## 网络与传输

瓦刻不实现遥测、云同步或素材上传。正常应用功能不会把视频、数据库或索引发送到项目维护者或任何第三方。

以下行为可能联网：

- **内置广告位（维护后台控制）**：发行构建可嵌入固定受信任的广告素材接口与落地域名，应用启动后由本机 Rust 后端请求该接口并把合规图文素材下载到本地缓存。普通设置不提供广告开关或接口输入，旧版本保存的相关值会被忽略并清除。此过程是**下载**，不上传任何用户数据；界面本身不连接任何外部服务器。用户点击广告卡时，应用用系统默认浏览器打开通过内置域名白名单校验的广告方落地页，URL 中包含广告位标识与本机生成的一次性点击标识（`click_id`），不含账号、游戏、文件或设备信息。接口缺失、离线、超时、配置非法或后台返回空活动时广告位静默隐藏。详见[广告位对接接口规范](./AD_INTEGRATION_SPEC.md)。
- 用户主动提交的问题反馈直传（需自行配置接口，默认仅保存到本地文件）；
- `npm ci`、Rust 依赖安装和其他开发工具访问各自的软件源；
- Windows 缺少 WebView2 时，安装器的 `downloadBootstrapper` 访问 Microsoft 服务；
- 用户主动打开 GitHub、许可或反馈链接；
- 应用更新检查（可在设置中关闭）。

测试中若观察到除上述之外的出站连接，应停止测试并报告。

### 广告位本地记录

广告活动有效并展示后，应用数据库会额外保存：广告素材元信息（标题、文案、广告主名、落地页模板）、每次点击的 `click_id` 与时间、按素材和日期聚合的曝光计数。这些记录用于与广告方后台数据核对收入，不含任何玩家或文件信息。

## 原始视频操作

- 扫描、预览、收藏、标签、备注和“移入回收站”不会修改原视频。
- “移入回收站”只改变应用索引状态。
- 只有用户在应用回收站再次确认“永久删除视频”后，应用才会尝试删除所选本地文件。
- 开发预览阶段只允许使用复制出的可丢弃素材测试永久删除。

## 保留、备份与删除

退出应用或卸载程序不应被理解为已经删除应用数据库、备份、缩略图缓存或用户原视频；正式卸载行为仍需干净 VM 验证。

需要清理测试数据时：

1. 完全退出瓦刻，并确认没有相关进程。
2. 先按[数据库恢复指南](./DATABASE_RECOVERY.md)备份整个应用数据目录。
3. 由测试负责人确认应用数据目录和缓存目录的实际路径；不要凭猜测删除宽泛的 `%APPDATA%`、`%LOCALAPPDATA%` 或用户目录。
4. 只删除已经核对属于本测试批次的应用数据；原视频目录必须单独确认。

正式发布前需要提供经过实机验证的“导出诊断、清理本地数据和卸载保留策略”入口。

## 反馈与附件

公开 Issue 中禁止上传原始视频、数据库、备份、WonderfulDb、LevelDB 或完整日志。截图和片段必须移除真实路径、玩家名、OpenID、账号/对局 ID、备注、好友信息和其他个人内容。完整规则见[小范围测试指南](./INTERNAL_TESTING.md)。

安全或隐私漏洞请按 [SECURITY.md](../SECURITY.md)私下报告。
